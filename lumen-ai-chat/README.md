# Lumen
**Stage of thought:** Perceive · **UI category:** AI Chat / Copilot

## Run it
1. Open `index.html` in a modern browser (or host on GitHub Pages).
2. Click **🔑 API key**, paste a free key from https://aistudio.google.com/apikey (stored only in your browser). Default model: `gemini-2.5-flash`; you can change it in the same box if Google renames models.

## Topic research (edit with your own findings)
1. **What it is:** A conversational interface where users talk to an AI in natural language.
2. **Where it is used:** products such as Copilot-style assistants, BI tools and workflow automation apps.
3. **Why it matters:** AI features are now a core part of modern web interfaces.
4. **Patterns observed:** Streaming-style replies, typing indicator, suggestion chips, mode switching.
5. **What this version adds:** a real working Google Gemini call, animated states, and a responsive layout.

## Tech
HTML, CSS, JavaScript, Google Gemini REST API. No frameworks.
